## Apple TV + MicroIPTV + KinoPub

В исходном файле было только `DOMAIN-SUFFIX,kino.pub,PROXY`; исключений DIRECT для видеосерверов не было. Добавлено точное `DOMAIN,api.service-kp.com,PROXY` рядом с существующим правилом KinoPub, до GEOIP,RU. Документация kinoapi.com подтверждает авторизацию, каталог и выдачу ссылок на этом узле. Это фиксирует политику служебного API без зависимости от географического определения его адреса.

`kinopub.fastcdn.pics` по исходникам mainsync-afk/lampa_kinopub обслуживает манифесты Lampa; медиасегменты могут идти отдельно. Его обязательность для MicroIPTV не доказана. Новое правило для него не добавляется; существующая обработка сохраняется.

cdn2cdn.com, cdn2site.com, digital-cdn.net, cdntogo.net не переведены DIRECT: нет журнала MicroIPTV и доказанной прямой доступности из сети пользователя. Готовится обратимая локальная проба. Доступность из среды аудита не подменяет проверку домашней сети.

Состояние на этом этапе: изменения конфигурации сохранены локально; коммит и отправка ещё не выполнены. Следующий шаг: завершить воспроизводимую статическую проверку, финальный отчёт, локальную инструкцию и отправку рабочей ветки.
